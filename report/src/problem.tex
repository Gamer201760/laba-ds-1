\CWHeader{Лабораторная работа \textnumero 2}

\CWProblem{
Для реализации словаря из предыдущей лабораторной работы необходимо провести исследование скорости
выполнения и потребления оперативной памяти. В случае выявления ошибок или явных недочётов требуется
их исправить.

Результатом является отчёт, состоящий из дневника выполнения работы, выводов о найденных недочётах,
сравнения работы исправленной программы с предыдущей версией и общих выводов.

Минимальный набор средств: утилита {\ttfamily gprof} и библиотека {\ttfamily dmalloc}, их можно
дополнять другими утилитами.

{\bfseries Исследуемая структура данных:} AVL-дерево.

{\bfseries Словарь:} ключ "--- регистронезависимая последовательность букв английского алфавита
длиной не более 256 символов, значение "--- число от $0$ до $2^{64}-1$. Команды:
{\ttfamily + word 34}, {\ttfamily - word}, {\ttfamily word}, {\ttfamily ! Save path},
{\ttfamily ! Load path}.
}
